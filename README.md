# Составитель расписаний

Веб-приложение на Python/FastAPI для генерации учебного расписания с учетом занятости аудиторий, преподавателей и групп. Основной алгоритм — жадный: сначала размещаются наиболее ограниченные занятия, затем для каждого занятия выбирается допустимая комбинация временного слота и аудитории.

## Запуск

```bash
docker compose up --build
```

Приложение будет доступно по адресу http://localhost:8000.

## Что реализовано

- ввод и редактирование временных слотов, аудиторий, преподавателей, групп и занятий;
- импорт и экспорт исходных данных в JSON;
- генерация расписания жадным алгоритмом;
- сравнение с последовательным и случайным порядком размещения;
- проверка конфликтов по аудиториям, преподавателям, группам, вместимости, типу аудитории и недоступности участников;
- демонстрационный набор данных по теме практики;
- автотесты для алгоритма и валидатора.

## API

- `GET /api/sample` — демонстрационный набор данных;
- `POST /api/schedule` — генерация расписания и сравнение алгоритмов;
- `GET /health` — проверка состояния сервиса.

## Тесты

```bash
docker compose run --rm app pytest
```

## Логика жадного алгоритма

1. Каждое занятие разворачивается в отдельные пары по полю `sessions`.
2. Для каждой пары рассчитывается количество статически допустимых вариантов: слот, аудитория, вместимость, тип аудитории, недоступность преподавателя и групп.
3. Занятия сортируются по сложности: меньше вариантов — раньше, выше приоритет — раньше, больше суммарная группа — раньше.
4. Для выбранной пары перебираются допустимые кандидаты. Предпочитаются варианты без повторения того же предмета в день, с меньшей дневной нагрузкой группы и преподавателя, с меньшим запасом вместимости аудитории.
5. После размещения занятость аудитории, преподавателя и групп фиксируется. Итоговое расписание дополнительно проходит независимую проверку конфликтов.
